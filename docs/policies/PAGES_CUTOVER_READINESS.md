# Library website discontinued

On 2026-09-11 the owner discontinued the Library website, including the frozen
four-article projection, its builder, assets, validators and preview workflow.
GitHub Pages hosting and the remaining registered site workflows are retired.

The Library remains public as a catalog and indexing/retrieval tool. Existing
research documents and provenance remain in the repository; they no longer
require a website rebuild or URL-compatibility projection. A future blog is a
separate product and is not implemented here.

This path is retained so references to the former cutover policy still resolve.
Earlier cutover and projection contracts can be read in Git history.
