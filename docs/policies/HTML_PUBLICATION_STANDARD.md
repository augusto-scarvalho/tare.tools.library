# Historical HTML publication profile

The `tare-research-html/1.0` profile describes retained research artifacts. The
Library website and its projection are discontinued; this profile is not a
publication prerequisite for new Library documents.

Existing HTML articles, metadata, editorial decisions and translation manifests
remain evidence with their original identities. Document-level validation and
translation provenance still serve ingestion and retrieval independently of
any website. Rendering into the former SIGNAL shell, incumbent parity and
public route compatibility are no longer Library responsibilities.

See [the retirement record](PAGES_CUTOVER_READINESS.md). The former projection
contract is available in Git history.
