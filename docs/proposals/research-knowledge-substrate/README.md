# Research Knowledge Substrate — Ideation & Refinement

Status: **PROPOSED / ACCEPTED FOR REFINEMENT**

This proposal extends the accepted seven-part `Research Lineage, Influence & Provenance` section with a repo-local enrichment architecture. It does not create Agent OS kernel primitives.

## Core direction

Immutable artifacts → Research Objects → Work identity → lineage → concepts/applicability → selected claims/evidence → influence/argument graph → temporal/curation events → rebuildable projections.

## Key guardrails

- external enrichment is evidence, not authority;
- discovery/similarity is not support;
- fuzzy identity never auto-merges;
- claims are selective, not bulk-extracted by default;
- embeddings/triplestores are optional projections;
- all history remains append-only / traceable;
- promotion to canonical tare.tools remains separate.
