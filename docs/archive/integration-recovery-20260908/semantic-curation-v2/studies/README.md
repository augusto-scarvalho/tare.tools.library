## Deeper studies that are not yet Git-materialized

Their identities, hashes, and rehydration status are tracked in [Deep-Artifact Rehydration Gaps](../catalog/REHYDRATION_GAPS.md).

## How to use an edition

A **study edition** preserves a historical scientific checkpoint. A **living study** is the current curated reading surface for that research question. Read the HTML when you want the richer original structure, bibliography, or historical framing; return to the living study for current cross-links, findings, proposals, experiments, and frontier questions.
