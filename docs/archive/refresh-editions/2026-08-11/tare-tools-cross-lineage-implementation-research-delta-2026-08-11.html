10. Cross-lineage architecture

The strongest result of the curation is convergence rather than proliferation. Historical documents used many useful local abstractions, but the current North Star can absorb most of them through a smaller semantic spine:

Project / Workspace
      ↓
Governance → Authority / Policy
      ↓
Workflow / Task semantics
      ↓
Eligibility → Routing → ExecutionBinding
      ↓
Runtime + Capability / Effect Plane
      ↓
Workspace / Sandbox / Resources
      ↓
Validation / Assurance
      ↓
Evidence / Provenance → Attribution / Qualification
      ↓
Reputation / Memory / Research feedback
      ↓
Evolution Control → governed promotion

Experience and Protocols are projections/boundaries around this spine rather than alternative owners of state. Observability is an operational projection. Research may challenge the architecture, but a finding becomes normative only through ADR/SPEC/BDD and implementation evidence.

11. Unified experimental program

  1. Parity before novelty: every replacement path gets a frozen-incumbent comparison.
  2. Evidence quality before volume: mutation/adversarial checks measure test/judge discrimination.
  3. Project-local plus held-out transfer: learn locally, evaluate global transfer conservatively.
  4. Fault and ambiguity injection: test crash, duplicate, timeout, stale owner, cancellation and partial effects.
  5. Temporal evaluation: measure long-running workflows, compaction, routing, resources and delayed incidents—not only final answer.
  6. Human/Experience evaluation: measure time-to-understand, intervention precision, approval error and attention cost.
  7. Economics: track cost-to-success and cost-to-trust separately.

ADR / Canonical Architecture
    ↓
Component SPEC / BDD
    ↓
Implementation Packet
    ↓
Code + Gates
    ↓
OutcomeEvidence / Audit
    ↓
possible future refresh

No refresh document may skip this chain. In particular, a recent preprint cannot create a primitive; a vendor feature cannot create Authority; a green benchmark cannot prove isolation; a successful route cannot grant reputation authority; and a translated historical document cannot be treated as current architecture.

13. Migration discipline — Strangler, compatibility and rollback

Cross-lineage implementation must remain incremental: introduce canonical contracts and adapters around the stable incumbent, prove parity, use shadow/canary where behavior changes, and remove legacy paths only after explicit rollback and deprecation criteria pass. This is Strangler Architecture / Branch by Abstraction applied to the Agent OS migration, not a greenfield rewrite.

  9. A2A Protocol specification — Current agent-to-agent federation protocol reference.
