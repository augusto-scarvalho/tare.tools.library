### Uma limitação importante — e como eu preservei a informação

Dos **102 artefatos catalogados**:

- **50 estão com os bytes originais completos dentro do ZIP**;
- **52 foram encontrados em outros chats através da File Library**, mas a interface de busca não expõe os bytes brutos desses arquivos para o filesystem desta execução.

Eu **não reconstruí esses 52 a partir de snippets**, porque isso criaria falsos “originais”.

Em vez disso, para cada um criei um registro contendo:

```text id="nvwhft"
nome exato
data de criação
File Library ID
domínio
família/version lineage
tipo do documento
notas de provenance
```

e gerei:

```text id="qujre9"
99_library-references/REHYDRATION_QUEUE.md
```

Assim nenhum trabalho fica silenciosamente esquecido. Em uma sessão futura, eu consigo pesquisar o arquivo pelo título/ID e recuperar seu conteúdo da File Library; se futuramente tivermos uma superfície que permita exportar os bytes, podemos preencher essas posições sem alterar a identidade do corpus.
