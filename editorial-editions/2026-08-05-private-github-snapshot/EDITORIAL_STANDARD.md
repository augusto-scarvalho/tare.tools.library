# tare.tools Research Editorial Standard — Historical Migration

This layer is derivative. Originals remain immutable.

## Required structure
1. Fixed sidebar and generated contents.
2. Editorial hero and provenance metadata.
3. Explicit CURRENT / TARGET / PROPOSED / RESEARCH boundaries.
4. Numbered source headings are preserved when present; numbering is never invented into source claims.
5. Tables and code remain responsive/readable.
6. Bibliography and inline links remain part of the source content.
7. English translations are derivatives linked to exact source hashes.
8. Research refresh is a separate operation from translation/editorial migration.
9. Operational logs, forensics, backlog and experiment rounds retain their original documentary class instead of being cosmetically promoted to scientific papers.
