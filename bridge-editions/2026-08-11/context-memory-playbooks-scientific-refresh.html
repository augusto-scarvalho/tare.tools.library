5. Scientific and engineering evidence — 2026 refresh

The 2026 memory survey [R01] shows the field has shifted from simple vector recall toward compression, hierarchical context, reflection and learned management while exposing contradiction, write filtering and privacy as persistent problems.

AdaCoM [R02] finds context policy should be agent-compatible: stronger and weaker agents benefit from different preservation/compression trade-offs. This supports qualification-specific context strategy rather than a single global compactor.

CWL [R03] provides strong evidence for typed, dependency-aware eviction with deterministic policies, avoiding summary hallucination and preserving causal structure. This maps naturally to dropping recoverable action episodes whose effects are durably recorded elsewhere.

MAGE [R04] treats memory as execution-state management with branches and revisions, reinforcing that semantic similarity alone is insufficient for long-horizon work.

Plans Don't Persist [R05] highlights the exact architectural hazard tare should avoid: durable plans must not exist only as prompt tokens. Active compression [R06] remains useful as an optimization, but not as the persistence model.

MCP's stateless 2026 core [R07] further supports not outsourcing memory/session semantics to an external protocol.
