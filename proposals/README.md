# Technical Proposals

Everything here is **PROPOSED / implementation research**, not TARGET or CURRENT authority.

A proposal survives in HEAD only when it contains problem-specific contracts, failure semantics, BDD/qualification ideas or migration decisions that remain useful. Generic “reconcile → adapter → shadow → canary” boilerplate belongs in policy, not repeated in every proposal.

Before implementation, reconcile against current `tare-tools` ADR/SPEC/BDD/source/Git.
