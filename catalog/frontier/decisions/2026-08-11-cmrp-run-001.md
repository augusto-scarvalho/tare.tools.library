# Cyclic Multi-Role Research Protocol — Run 001 Decision

**Date:** 2026-08-11  
**Status:** `ADAPT / ACCEPT_FOR_EXPERIMENTAL_SHADOW_USE`

The project owner asked the current ChatGPT runtime to execute the proposed research roles sequentially and cyclically instead of spawning unavailable subagents. Run `CMRP-2026-08-11-001` executed eleven frozen functional-role artifacts and one explicit adversarial revision cycle.

## What this decision accepts

- same-model staged role execution as an experimental research-process technique;
- frozen intermediate artifacts, role missions/forbidden moves and revision deltas;
- explicit contrary-evidence search and adversarial review;
- executor/provenance metadata on every run;
- functional role separation as distinct from epistemic independence.

## What this decision does not accept

- role count as EvidenceFamily diversity;
- same-model final audit as strict proof;
- persona prompting as a proxy for cognitive diversity;
- claims that CMRP is superior to compute-matched iteration or true multi-agent research;
- new Agent OS primitives.

## Evidence status

The run is an N=1 methodological demonstration. It established feasibility and produced material self-corrections, but comparative efficacy remains OPEN. The next research step is the compute-matched qualification pointer in the Research Frontier.
